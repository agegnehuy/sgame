# Pilot Handoff Package Checklist

Use this to assemble the exact package sent to facilitators/schools.

## 1) Build artifacts

- [ ] Release candidate APK file
- [ ] Build version and date note
- [ ] Device compatibility note (tested models)

## 2) Facilitator quick-start

- [ ] Install steps (APK install permissions)
- [ ] First-launch setup (language, profile creation)
- [ ] How to start missions
- [ ] How to switch language
- [ ] How to export report

## 3) Session operation guide

- [ ] Recommended session duration
- [ ] Suggested number of children per device
- [ ] Basic supervision tips
- [ ] Retry guidance for struggling learners

## 4) Data/report handling

- [ ] Where exported report files are stored
- [ ] How to identify latest report file
- [ ] How to share report back with foundation team

## 5) Known issues list

- [ ] Known issue log included (if any)
- [ ] Workarounds documented clearly
- [ ] Severity tag for each known issue

## 6) Support channel

- [ ] Contact person name
- [ ] Response expectation (e.g., same day)
- [ ] Required bug evidence format (screenshots, steps, device)

## 7) Pilot feedback form

- [ ] Short feedback questions for facilitators
- [ ] Learning/engagement observation prompts
- [ ] Technical issue reporting section

## Final sign-off

- [ ] Tech Lead signed
- [ ] QA lead signed
- [ ] Education/SME signed
- [ ] Program owner signed
